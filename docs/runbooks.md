# Operational Runbooks

## Incident response steps
1. Identify the issue
2. Triage
3. Mitigate
4. Resolve
5. Post-mortem

## Recovery procedures
1. Rollback to previous deployment
2. Restore from backup
3. Verify system health

## Offline mode fallback guide
If the system is offline, the Service Worker will serve cached static assets, OpenStreetMap tiles, and fallback backend API responses.
